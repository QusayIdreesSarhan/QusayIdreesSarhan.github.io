# QusayIdreesSarhan.github.io

Academic personal website for Dr. Qusay Idrees Sarhan.

## GitHub Pages

1. Create a repository named `QusayIdreesSarhan.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `Qusay-CV.pdf`.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Open `https://qusayidreessarhan.github.io`.
